# 🍔 Restaurant Ordering System

A simple command-line restaurant ordering system built with Python.

## Features

* Displays available menu items and prices
* Allows users to order multiple items
* Supports item quantities
* Calculates the final bill
* Handles invalid item names
* Interactive menu using `match-case`

## Concepts Used

* Functions
* Dictionaries
* `if-else`
* `while` and `for` loops
* User input
* `match-case`
* f-strings

## How to Run

Make sure Python 3 is installed, then run:

```bash
python restaurant.py
```

Follow the prompts in the terminal to view the menu and place an order.
